# 업무 내용과 실행 원본 연결

사용자 요구: UUID와 제목만으로 업무를 추측하지 않고 실패 내용, 대화·응답과 연결된 Projects 업무를 확인한다.

- Assistant 상세, 연결된 Run, 업무 node, 묶음, Projects 목록에서 원본 업무 링크와 설명·수용 기준 조회를 제공한다.
- 본문은 사용자가 열었을 때 기존 `GET .../tasks/{id}/review`로 읽는다. 원본 Project 접근과 응답의 Task/Project를 확인하며 Track 이벤트 원장에 본문을 저장하지 않는다.
- 접근 철회·조회 실패·대상 변경·닫기 때 이전 본문을 숨긴다. 열린 본문은 15초마다 원본을 재확인한다. HTML은 텍스트로 표시한다.
- Assistant의 등록된 `uiBaseUrl`과 검증된 instruction/execution 식별자로 원본 실행을 연다. 결과는 원본의 결과 조회·Note 링크에서 확인한다. 대화·응답 본문을 Track이 직접 가져오는 별도 reader는 추가하지 않는다.
- 보호된 Demian 시도는 부모 Assistant 실행으로 연결한다. 과거 실패 시도와 부모 실행의 최신 재시도 결과를 구별한다. 일반 Demian은 기존 원본 Session 링크로 대화를 연다.
- 실패 코드는 원본 분류를 설명하며 실제 상세 원인을 추정하지 않는다. 원본이 상세 오류를 제공하지 않는 경우를 명시한다.
- Entra 인증과 읽기 권한을 유지한다. writer·새 QA 실행·Persona/Demian 배포·원본 DB 변경은 필요 없다.

수용 조건: 업무 설명/수용 기준과 원본 Task 링크, 정확한 원본 실행 링크, 실패 코드 설명, 접근 철회·대상 변경 시 본문 제거, 실제 기존 업무의 브라우저 확인.

## 검증

- 타입 검사와 격리된 Vite build 통과. 복구용 `dist/web` 보존.
- 관련 회귀 테스트 50건 통과. 정확한 Task/Project, 본문 한도, 응답 지연·접근 철회, 안전한 출처 주소, 원장 호환성 확인.
- 새 화면/API와 운영 DB의 복사본에서 실제 원본 읽기 확인. Edge 157, 1440×1000, 합성 응답 없음, 쓰기 요청 없음.
- 기존 실패 시도와 성공 시도에서 같은 부모 실행·업무 원본 링크 대조. 실제 업무 설명 253자와 수용 기준 4개 표시, 닫기·Run 이동 시 본문 제거, JS 오류 없음.
- 업무 본문 읽기가 불필요한 전체 Native 수집을 기다리던 경로 제거. 원본 Project 권한은 읽기 전후 각각 확인.
- 전체 로컬 테스트에서는 이번 변경 밖 Windows 프로세스 조회 검사들이 10초 타임아웃으로 실패. 실행 중단으로 전체 로컬 통과를 주장하지 않음.

배포 결과는 실제 운영 전환 후 기록한다.
