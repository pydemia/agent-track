# 사이드바 경계 드래그와 내부 스크롤

2026-11-19 사용자 요구: 별도 너비 슬라이더 대신 Note처럼 경계를 끌어
너비를 바꾸고 작은 창에서도 전체 내용을 볼 수 있게 한다.

- 너비 슬라이더를 제거하고 오른쪽 경계의 6px 입력 영역을 사용한다.
  별도 손잡이는 그리지 않는다. 180–360px 범위와 계정별 저장 설정을 유지한다.
- 드래그 중에는 미리보기만 변경하고 놓을 때 저장한다. Escape·pointer cancel·
  창 blur·접기 시 미완료 드래그를 취소한다.
- 경계를 키보드로 선택하면 좌우 방향키 16px, Shift 64px,
  Home/End로 최소/최대 너비, 두 번 클릭으로 기본 240px를 적용한다.
- 사이드바를 현재 viewport 높이로 제한하고 내용 래퍼에 독립 스크롤을 둔다.
  내용은 줄어들지 않으며 하단 안내도 스크롤로 접근할 수 있다.
- 모바일 drawer의 열기·Escape·focus 복귀와 접기 기능을 보존한다.

참조한 실제 구현은 Note의 `WorkspaceSidebarResize.tsx`와
`WorkspaceSidebarPanel.tsx`, Pydemia UI의 `resizable-panels.tsx`다.
Note의 preview/commit·취소·키보드 동작을 현재 Track 구조에 적용했다.
Pydemia UI의 별도 8px 패널 손잡이와 비율 기반 grid는 이번 요구와 달라
추가하지 않았으며 기존 React·CSS와 색상 token을 유지한다.

검증: 후보 정적 파일과 실제 운영의 읽기 전용 API를 연결한 Edge에서
드래그·키보드·취소·새로고침 후 저장·접기 후 너비 보존을 확인했다.
1440×900, 900×450, 390×450에서 내부 스크롤·하단 접근·모바일 focus 복귀,
가로 넘침과 JavaScript 오류 없음도 확인했다. 별도 합성 메시지나 쓰기 요청은
사용하지 않았다. 운영 반영의 revision·배포 후 검증은 PR에 별도로 기록한다.
